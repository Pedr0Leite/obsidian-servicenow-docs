## Resolution

The user that gets created and assigned for the SAM scheduled jobs is 'sam.pa.jobs.scheduler'

Observing this condition as there is no default role(s) being assigned to the user 'sam.pa.jobs.scheduler' out of the box and it has been left for a user's choice.

Post installation, if the error is seen, a customer facing incident has to be raised and a suggestion can be made to update the role(s) of the user "samp.pa.jobs.schedule" to have the role schedule\_admin. Here are a here are a few other roles which are good to have - import\_scheduler, template\_scheduler.
