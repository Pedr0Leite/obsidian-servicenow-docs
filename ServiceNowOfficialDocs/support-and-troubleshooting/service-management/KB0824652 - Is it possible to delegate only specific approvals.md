## Is it possible to delegate only specific approvals?

  

### Issue

The user wanted to know if it was possible to separate off delegate approvals for only one type of task (such as incident or Service Catalog), versus also including HR approvals.

### Resolution

Unfortunately, this is not possible with an Out of Box (OOB) configuration. Approval delegation allows the selected delegate to access all approvals, regardless of application. Attempting this type of functionality would be a customization, and as such, is out of scope for Support.  
  
In light of this, it was recommended that if the user needed this custom functionality, they should speak to their internal development team regarding it.  
  
Additionally, the resource of the ServiceNow [Community page](https://community.servicenow.com/community "Community page") was provided as many users discuss and assist one another with custom implementations there.
