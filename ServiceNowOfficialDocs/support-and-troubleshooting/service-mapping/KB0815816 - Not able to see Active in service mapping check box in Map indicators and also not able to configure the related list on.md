## Not able to see Active in service mapping check box in Map indicators and also not able to configure the related list on the Dependency View map to be able to see Incidents, Problems and other.

  

### Issue

We are trying to see alert, outages and incidents from service map view So I checked in the map indicator and there service mapping check box. Because of this we couldn't see the alerts in the service map view.

### Release

All Releases.

### Cause

  
Releases older than Orlando will have it as Active and from Orlando release, you will see it as Active in Service Map for Map Indicators.

### Resolution

You should be able to configure the Service Map from view related list and able to see the Incidents, Outages, Problems, Changes, Affected CIs and other as shown in the screenshot. By default, you see the page load in Edit view for the discovery logs and changes.  
  
You should be able to configure the related list from the three dash icon (Hamburger Icon) at the end of the corner.
