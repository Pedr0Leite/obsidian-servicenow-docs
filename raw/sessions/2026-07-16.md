Always check the full set of Cosmic extensions (`pop-cosmic`, `cosmic-dock`, `cosmic-workspaces`, `pop-shell`) when any Cosmic UI element stops responding.
- documents: A GNOME Shell in-place restart (`killall -3 gnome-shell`) is safe on X11 and worth trying first, but won't fix issues caused by a disabled extension.
