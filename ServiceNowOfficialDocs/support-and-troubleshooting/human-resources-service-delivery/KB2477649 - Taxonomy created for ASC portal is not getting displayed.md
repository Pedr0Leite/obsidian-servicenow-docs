## Taxonomy created for ASC portal is not getting displayed

  

### Issue

Taxonomy created for ASC portal is not getting displayed in the asc portal.  
  

### Release

All

### Resolution

1.  Taxonomy will not work for Alumni
2.  Taxonomy topic related pages and widgets are not opened up for external users, its only for internal employees.
3.  Which means the topics will not be visible on Alumni portal, as it is for external users.
4.  There is no workaround for this as this is working as expected.
