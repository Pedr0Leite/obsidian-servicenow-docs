## Issue

Symptoms:

If a user removes a dot-walked field that an Administrator has added to a list, it is then not visible on the left hand side of the 'Personalize List Columns' slushbucket to be re-added to the displayed list.

1\. Remove 'Caller.Email' field by moving to left side of slushbucket.

![](sys_attachment.do?sys_id=44070f6397ab3d948a073cbe2153afb0)

2\. It is now visible on left side. Press 'OK' button to save changes.

![](sys_attachment.do?sys_id=98070f6397ab3d948a073cbe2153afb3)

3\. Re-open popup, 'Caller.Email' is not available to add to list.

![](sys_attachment.do?sys_id=9c070f6397ab3d948a073cbe2153afb5)

In order for the field to be visible in the list again, the user is required to click the 'Reset to column defaults' button. Any other changes made will then also need to be reconfigured.
