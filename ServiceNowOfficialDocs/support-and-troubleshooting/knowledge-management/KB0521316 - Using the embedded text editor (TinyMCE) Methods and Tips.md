## Using the embedded text editor (TinyMCE): Methods and Tips

  

## Description

The knowledge base provides a full-featured **WYSIWYG** ("_What You See Is What You Get_") HTML editor, including an HTML code editor. This editor widget is called [TinyMCE](https://tiny.cloud "TinyMCE the cloud text editor"). An HTML field allows users to define how field content is rendered. Use the HTML editor to create and modify the content of a knowledge article. Knowledge articles, service catalog item descriptions, release documentation, and HTML content blocks are common examples of HTML fields. 

The HTML editor is divided into two sections.

-   **Toolbar** - Controls how text and images are displayed, import media, create hyperlinks, and a variety of other options.
-   **Text Pane** - Control text and image placement, and write the text content for the article.

### Using the toolbar

The buttons on the toolbar allow you to edit every aspect of your document. In _WYSIWYG_ mode, the HTML editor provides tools similar to a word processing program.

![tinymce5\_toolbar\_nowsupport.png](sys_attachment.do?sys_id=2504dc18934196105736b25d6cba1036)

At the bottom of the editing window, the editor displays the path of HTML tags that are applied to the text at the cursor. The following sections list HTML tools available with the TinyMCE editor.
