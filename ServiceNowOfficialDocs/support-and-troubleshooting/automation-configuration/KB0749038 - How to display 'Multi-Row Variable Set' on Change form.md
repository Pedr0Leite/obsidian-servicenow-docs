## How to display 'Multi-Row Variable Set' on Change form

  

### Issue

# Description

Unable to view Multi-row variable set in the Change form within the platform UI.

# Procedure

From the Change record select the "Additional Actions" button > Select "Configure" > Select "Form Layout"

Make sure that you have the "Change Variable Editor" moved over from the "Available" slush-bucket to the "Selected" slush-bucket in order to display the Multi-Row Variable set. 

You will now see the Change Variable Editor in the Change record.

# Applicable Versions

All versions
