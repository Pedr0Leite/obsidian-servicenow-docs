## "Import Messages" Button is not showing on the HR Agent Workspace

  

### Summary

"Import Messages" Button is not showing on the HR Agent Workspace 

### Release

Any

### Instructions

  
  
Check if the sn\_now\_teams.tenant\_id and sn\_now\_teams.app\_client\_id properties have assigned values
