## Dynamically add Survey questions based on Assessment Instance expired 'Due date' field

  

### Summary

You have a scenario where you would like that additional questions should be added to a survey as soon as the due date has passed.  
  
As an example, if you have a survey with one question that is due on 01-01-2021, as soon as it is 02-01-2021, if the user has not taken the survey, you would like another question to be dynamically added in order to understand why the user did not take it on time.

### Instructions

Unfortunately, OOB there is no configuration as such to dynamically add questions to the survey based on the due date.  
  
That could maybe be achieved through some implementation/customization which is out of scope for Technical Support as we focus on break-fix issue with the out of the box product.  
  
Regarding customization approach from the community, we are not aware of any customisation approach that can be used to achieve this.  
Also unfortunately, there is no documentation/news if this feature is planned for future releases.  
  
Considering that, it would be a good idea for an enhancement request if you would like this functionality to be added to our product.  
Customers can now raise enhancement requests (called 'Ideas' in this context) in the ServiceNow Community, where other customers can vote for them.

The more votes an Idea has, the more likely it is to be considered for a future release.  
See [Idea Management for customer enhancement requests](https://hi.service-now.com/kb_view.do?sysparm_article=KB0755878) for further details.
