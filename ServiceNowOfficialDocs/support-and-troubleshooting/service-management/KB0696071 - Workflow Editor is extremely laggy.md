## Workflow Editor is extremely laggy

  

### Issue

Workflow Editor is extremely laggy

### Release

Kingston+

Internet Explorer 11

### Cause

Internet Explorer 11 does not have an advanced javascript engine

### Resolution

Internet Explorer 11 does not have an advanced javascript engine and that is the reason we are seeing a slow performance when we open the workflow editor.

  

The issue will be resolved if browsers such as Google Chrome, Microsoft Edge, or Firefox are used.
