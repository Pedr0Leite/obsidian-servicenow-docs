## Can you have more than one archive rule on a specific table?

  

### Issue

Is it possible to have more than one archive rule on a specific table?

### Release

All

### Resolution

The Archive Rules module in the System Archiving application allows for more than one rule per table whether or not the rule is active or inactive.
