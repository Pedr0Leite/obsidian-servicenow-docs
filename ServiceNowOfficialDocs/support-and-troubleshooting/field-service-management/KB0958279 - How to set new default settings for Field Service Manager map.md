## How to set new default settings for Field Service Manager map

  

### Summary

If you have enabled the Service Management Geolocation plugin ('com.snc.service\_management.geolocation') to display your Agent Map (http://<yourinstancename>.service-now.com/sm\_core\_geo\_location.do), you may want to change some default settings as the initial zoom level, the controls size or even set an advance configuration.

Note: the Google Maps Platform key must be entered into the appropriate Google Maps property.

### Instructions

To set new default settings such as initial zoom level, controls size, etc., navigate to Map Pages > SM Core Geo Dispatch Map and edit the the desired fields.

For example you can set the zoom level starting at 1 (the lowest level).

You can also edit other Field Service Management maps navigating to their respective Map Pages such as Manager Map, My SLA map, etc.
