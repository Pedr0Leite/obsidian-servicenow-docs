## Display a Change Request's related list in CAB Workbench

  

### Issue

# Symptoms

* * *

Unable to display a related list for a change request on the CAB workbench

# Release

* * *

Jakarta Patch 9c

# Cause

* * *

When selecting a change request in the CAB Workbench, some form sections are visible; however, customization is required to display a change's related list. Adding an embedded list to a form section does not help as embedded list are not supported in service portal.

# Resolution

* * *

User customization is required on the widget that displays the change form to accomplish this need.
