## CMDB dependency view doesn't show all relationships

  

### Issue

# Description

* * *

CMDB dependency view doesn't show all relationships

# Procedure

* * *

1\. The no.of relationships that are shown on the BSM are controlled by system property -> glide.bsm.max\_num\_rels   
2\. The default value is 100  
3\. To view more relations on the BSM, adjust the property accordingly.   
  
Ref: [https://docs.servicenow.com/csh?topicname=r\_InstalledWithDependencyViews.html&version=latest](https://docs.servicenow.com/csh?topicname=r_InstalledWithDependencyViews.html&version=latest)
