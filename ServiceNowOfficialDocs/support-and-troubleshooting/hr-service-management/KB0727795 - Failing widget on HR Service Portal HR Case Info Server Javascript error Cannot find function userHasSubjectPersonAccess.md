## Failing widget on HR Service Portal HR Case Info "Server Javascript error: Cannot find function userHasSubjectPersonAccess"

  

### Issue

# Symptoms

* * *

Failing widget on HR Service Portal HR Case Info "Server Javascript error: Cannot find function userHasSubjectPersonAccess"

# Release

* * *

London 

# Cause

* * *

Customized script include "hr\_PortalUtil" 

# Resolution

* * *

Revert the "hr\_PortalUtil" script include to the latest version and then reapply your customizations
