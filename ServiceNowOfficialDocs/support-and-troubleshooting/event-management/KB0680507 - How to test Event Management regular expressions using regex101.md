## How to test Event Management regular expressions using regex101

  

### Issue

How to test Event Management regular expressions using regex101

# Issue

* * *

In the [Event Management](https://docs.servicenow.com/csh?topicname=c_EM.html&version=latest "Event Management") product, when configuring [Event Rules](https://docs.servicenow.com/csh?topicname=create-event-rules.html&version=latest "Event Rules"), the [Event Input](https://docs.servicenow.com/csh?topicname=event-input-information.html&version=latest "Event Input") pane that is included in the steps to create an event rule provides a reference to the information that you can use when configuring an event rule. In the Transform and compose alert output section, you can also drag the information into the required fields to customize alert content, you can compose text using regular expression (regex) format conventions. This document explains how to configure [https://regex101.com](https://regex101.com) to test and validate these regular expressions.
