## Customer Registration Requests using Invalid Registration Codes not being triggered

  

### Issue

# Overview

* * *

As per the product documentation provided in the below link, Admin users will approve pending registration requests with invalid registration code.

[Approve a registration request with an invalid registration code](https://docs.servicenow.com/csh?topicname=t_ApproveRegRequestWithInvalidCode.html&version=latest "Approve a registration request with an invalid registration code")

# Subject

* * *

Functionality in Customer Service Management (CSM) for end users is to register in an account using a valid registration code. But mentioned product document says that end users can register with an invalid registration code which is not the current functionality of the CSM - Register.

Product team confirmed that mentioned will be corrected as end users can register in CSM only with the valid registration code in an account.
