# Steps to Implement

* * *

If you have attempted to troubleshoot a clone that does not start and determine that you need to restart the clone, follow these steps:

1.  Type **Clone** into the navigation filter. 
2.  Open the clone history. 
3.  Sort **Created Z to A** and locate the last clone that was requested. 
4.  Open the record and select the **Restart clone** UI action.
