## Request is not associated with the incident when created from "create request" UI action.

  

### Issue

# Symptoms

* * *

Request is not associated with the incident when created from "create request" UI action.

Release

* * *

London

# Cause

* * *

The catalog item that is being requested should have "use cart layout" active.

# Resolution

* * *

Check "use cart layout" on the catalog item
