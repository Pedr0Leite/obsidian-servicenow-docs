# Overview

# Event Management - IBM NetCool Connector Support for OMNIbus 8.1

* * *

As per the docs URL below, the connector validation has been performed on IBM NetCool/OMNIbus 7.3.1.

However, as per confirmation of the developers, it is likely that OMNIbus version 8.1 will work as well as the NetCool API have backward compatibility.
