## Issue

Custom action works as expected when tested. Adding the same action to a flow does not allow activation and shows error "_**Failed to deserialize Complex Object Unexpected character**_".

## Resolution

Copy the custom action and use it in flow, this should fix the error and allow flow to be activated.
