## Troubleshooting a MID Server that is down or not responding

  

### Issue

This article guides you through the process of troubleshooting a MID Server that is down or not responding. It provides steps to help you eliminate common causes for your problem by verifying that the configuration of your networking and server is correct.

### Symptoms

-   MID Server is down
-   MID Server does not start or restart
-   MID Server auto-upgrade fails
-   Cannot log into MID Server
-   Probe does not work

### Release

All releases

### Resolution

Validate that each step is true for your environment. Each step links to a knowledge document for possible causes and corrective action. The steps are ordered in the most appropriate sequence to isolate the issue and identify the proper resolution.

1.  Verify that the MID Server was set up correctly. For more information, see [Best practices on setting up your MID Server](/kb?id=kb_article_view&sysparm_article=KB0535145 "KB0535145: Best practices on setting up your MID Server").
2.  Verify that the MID Server is actually down. For more information, see [Confirm your MID Server is actually down by checking event processing](/kb?id=kb_article_view&sysparm_article=KB0535146 "KB0535146: Confirm your MID Server is actually down by checking event processing"). 
3.  Verify that you have the correct credentials on the MID Server. For more information, see [Determine if you have the correct credentials on the MID Server](/kb?id=kb_article_view&sysparm_article=KB0535149 "KB0535149: Determine if you have the correct credentials on the MID Server").
4.  Verify that the agent log does not contain MID Server errors. For more information, see [Review the Agent Log for MID Server errors](/kb?id=kb_article_view&sysparm_article=KB0535148 "KB0535148: Review the Agent Log for MID Server errors").
