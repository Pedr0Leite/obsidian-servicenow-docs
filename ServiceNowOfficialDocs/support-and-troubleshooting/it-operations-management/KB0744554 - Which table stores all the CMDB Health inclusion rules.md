## Which table stores all the CMDB Health inclusion rules?

  

### Issue

# Overview

CMDB Health inclusion rules are generally defined and added through CI class manager, at individual class levels. These are actually stored in cmdb\_health\_config table.

# Subject

In the App navigator, you can type in cmdb\_health\_config.list, to open the list view of this table to review all the inclusion rules at one place
