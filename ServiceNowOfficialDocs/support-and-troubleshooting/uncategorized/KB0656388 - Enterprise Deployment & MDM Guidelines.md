## Enterprise Deployment & MDM Guidelines

  

### Issue

Administrators can use an Enterprise Mobile Management(EMM) suite such as AirWatch or MobileIron to distribute and manage the ServiceNow Mobile App on user devices.

The custom app config key “SNDefaultInstanceURL” can be configured for seeding a default instance URL already added to the app when deployed. No other custom variables are currently supported.

https://docs.servicenow.com/csh?topicname=enterprise-mobility-management.html&version=latest
