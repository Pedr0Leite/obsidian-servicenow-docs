## ITAM - SAM - SAP - ABAP - USMD\_TT\_TAB512 table type error while TR deployment at SAP system

  

### Summary

Issue: While deployment of SAM SAP ABAP Transport file version 5.0.1 below error shows up  
 "Syntax error in line 000015, Type 'USMD\_TT\_TAB512' is unknown."

Root cause - USMD\_TT\_TAB512 table type is not available on the SAP system. 

  
Resolution: Steps to resolve are mentioned in the attached doc "[TAB512\_SAP\_error\_resolution.docx](https://support.servicenow.com/sys_attachment.do?sys_id=6e22a67d931d4a10def533527cba105a&sysparm_this_url=u_kb_template_kcs_how_to_for_cs.do%3Fsys_id%3Ddecfd275931d4a10def533527cba109b%26sysparm_domain%3Dnull%26sysparm_domain_scope%3Dnull%26sysparm_view%3D)"

### Release

Fix applicable to Release or environment - 

"SAP ABAP for Software Asset Management" version 5.0.1 which is compatible with Utah, Vancouver, Washingtondc
