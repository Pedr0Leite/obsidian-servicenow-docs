## Creating the HR case checklist from the Agent Workspace

  

### Summary

1\. To create a one-time checklist directly into an HR case, create the case in HR Service Delivery Agent Workspace.  
2\. Go to the platform HR Case Management and open the case you created.  
3\. Scroll down and select the down arrow and select Create New  
4\. Enter instructions.

Please note that creation of the checklist can be done only from the backend. It is impossible to do it from the Agent Workspace UI.
