## The samp\_subscription\_usage table is missing

  

### Issue

The samp\_subscription\_usage table is missing, preventing access to the dashboard.

### Release

Version 13, or lower, of the SaaS License plugin.

### Cause

The samp\_subscription\_usage table is included in version 14 of the SaaS License plugin, available in the Xanadu release.

### Resolution

Upgrade version 14, or higher, of the SaaS License plugin.
