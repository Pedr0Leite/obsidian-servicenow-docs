## How to dynamically add catalog items using the catalog order guide

  

### Issue

  
  

# Description

* * *

Unfortunately, OOB functionality does not allow us to have the same item in multiple tabs in the order guide. 

# Procedure

* * *

Unfortunately, OOB functionality does not allow us to have the same item in multiple tabs in the order guide. 

As mentioned in this community article, we can either use "Continue Shopping" button and add an item one by one or there needs to be a heavy customization to enable this functionality and I would kindly like to let you know customization is out of our Support's scope.

[https://community.servicenow.com/community?id=community\_question&sys\_id=9d3fc7e1dbdcdbc01dcaf3231f96193d](https://community.servicenow.com/community?id=community_question&sys_id=9d3fc7e1dbdcdbc01dcaf3231f96193d)

# Applicable Versions

* * *

Kingston and earlier
