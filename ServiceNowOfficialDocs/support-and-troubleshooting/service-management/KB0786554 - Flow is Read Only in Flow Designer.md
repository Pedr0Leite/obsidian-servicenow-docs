## Flow is Read Only in Flow Designer

  

### Issue

Unable to edit a Flow in the flow designer, shows as READ ONLY FLOW.

![](sys_attachment.do?sys_id=77a23f38db8478d066e0a345ca961972)

### Release

New York Patch 2

### Cause

The issue is due to Instance Upgrade is in InProgress and because of it, flow is on READ ONLY.

### Resolution

The issue is resolved after the instance is upgraded and able to edit the flow activities
