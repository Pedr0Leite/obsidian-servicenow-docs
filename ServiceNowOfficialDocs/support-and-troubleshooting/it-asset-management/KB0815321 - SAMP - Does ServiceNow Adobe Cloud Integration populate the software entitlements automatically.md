## Issue

Does **ServiceNow Adobe Cloud Integration** populate the **software entitlements** automatically?

## Resolution

No, ServiceNow SAMP Adobe Cloud Integration **does not** populate the software entitlements. it only populates data about **Adobe software subscriptions** in '**samp\_sw\_subscription**' table.
