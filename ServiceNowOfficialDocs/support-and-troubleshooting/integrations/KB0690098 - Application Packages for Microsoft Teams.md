## Application Packages for Microsoft Teams

  

### Issue

ServiceNow offers two different application packages for Microsoft Teams:

-   Now Actions app for integrating ServiceNow notifications with Microsoft Teams
-   Now Virtual Agent app for integrating the Virtual Agent bot with Microsoft Teams

### Now Actions application

Use the Now Actions app to enable users to receive their ServiceNow platform notifications in the Microsoft Teams messaging application.

1.  Download the Now Actions app package (now-actions-teams.zip) [here](https://support.servicenow.com/sys_attachment.do?sys_id=3df374f48770fe9057288519dabb356d "here").
2.  Install the downloaded Now Actions app zip file into the Microsoft Teams Tenant Apps Catalog. Use this catalog to distribute line-of-business applications to your organization. For details, see [Publish apps to the Microsoft Teams Tenant Apps Catalog](https://docs.microsoft.com/en-us/MicrosoftTeams/tenant-apps-catalog-teams "Publish apps to the Microsoft Teams Tenant Apps Catalog") in the Microsoft Teams documentation.

### Now Virtual Agent application

Use the Now Virtual Agent app to enable users to run Virtual Agent bot conversations in the Microsoft Teams messaging application.

1.  Download the Now Virtual Agent app package (now-virtual-agent-teams.zip) [here](https://support.servicenow.com/sys_attachment.do?sys_id=0af374f48770fe9057288519dabb3570 "here").
2.  Install the downloaded Now Virtual Agent app zip file into the Microsoft Teams Tenant Apps Catalog. Use this catalog to distribute line-of-business applications to your organization. For details, see [Publish apps to the Microsoft Teams Tenant Apps Catalog](https://docs.microsoft.com/en-us/MicrosoftTeams/tenant-apps-catalog-teams "Publish apps to the Microsoft Teams Tenant Apps Catalog") in the Microsoft Teams documentation.
