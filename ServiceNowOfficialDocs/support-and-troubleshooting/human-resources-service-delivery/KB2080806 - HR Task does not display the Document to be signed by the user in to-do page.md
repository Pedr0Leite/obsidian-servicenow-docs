## Issue

Document Template has been configured but in the HR template there is no option to add this template, hence, in the to-do page to sign/complete the form in Portal, the form is not displayed  
  

## Resolution

1\. Add the "Document template" field to the HR Template form.  
2\. Select the corresponding document template in the "Document template" field.  
3\. When creating a new HR Case a new DOC record will be created for the user to complete the form in portal in to-dos page.
