## When we installed the Software Asset Management Foundation plugin, the software asset management(sn\_itam\_samp) plugin was also installed.

  

### Summary

When we installed the Software Asset Management Foundation plugin, the software asset management(sn\_itam\_samp) plugin was also installed.

This is expected behaviour. 

The Software Asset Management extension is active out of the box on Software Asset Management Foundation.  
Hence, Software Asset Management(sn\_itam\_samp) will be installed when the Software Asset Management Foundation plugin is installed

**Note**: Software Asset Management(sn\_itam\_samp) is different from Software Asset Management Professional(com.snc.samp)
