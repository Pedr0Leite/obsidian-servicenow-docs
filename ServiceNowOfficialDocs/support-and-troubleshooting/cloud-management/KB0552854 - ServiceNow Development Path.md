## Issue

ServiceNow Development Path 

Overview

* * *

Having a well-defined migration process is important to any ServiceNow implementation for moving system changes and data not captured by update sets from one instance to another.  It is not uncommon to have multiple developers or development streams during an implementation as well as each developer working with multiple update sets. It is also common for developers to assign the duty of migrating completed update sets to another member of the implementation team.  The key here is to have a documented process that addresses the topics described so that when update sets are moved and applied to the target instance, the changes work as expected.
