## Event Rules list, the form does not behave as a standard list/form as it is a custom UI. Also, the filters saved as favorites does not work.

  

### Issue

# Description

Event Rules list, the form does not behave as a standard list/form as it is a custom UI. Also, the filters saved as favorites does not work. 

# Procedure

  
1\. Navigate to Event Rules and open the list   
2\. Use mouse cog wheel to open the records record in a new tab and it takes to em\_match\_rule.do deprecated page or copy the link and open in a new page. Reproducible in chrome & Edge browser   
3\. issue is not reproducible when you use the cmd key in mac to open the records in a new tab. Didn't work using control key on windows.   
4.also for Event Rules apply a filter(example filter inactive rules) create a Favorite by Hamberger icon.   
5\. Go to favorites and open the one which is saved and filter doesn't apply. 

# Applicable Versions

All the releases after Jakarta Release.

# Additional Information

Above steps mentioned do not work for event rules, which work for a standard list/forms.
