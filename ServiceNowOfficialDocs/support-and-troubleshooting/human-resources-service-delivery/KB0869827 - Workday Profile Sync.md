**Configuration field navigation**

| Field | Navigation in Workday |
| --- | --- |
| Department organization Type ID | Worker Profile>job icon > Organizations(a list of organization will be shown below)> choose any organization type in organization type column> click on related action of organization type> Integration IDs> View IDs |
| Location usage ID | Access view location task in workday> search for any location> click on related action of the location usage e.g. business site and select integration IDs> View IDs |
| Location Phone Device Type ID | Access View Reference IDs task in workday> search for Phone Device Type in business object box and click ok> Select the vlaue for Landline in Reference id value column. |
| Location Fax Phone Device Type ID | Access View Reference IDs task in workday> search for Phone Device Type in business object box and click ok> Select the vlaue for Fax in Reference id value column. |
| Location Communication Usage Type ID | Access view location task in workday> search for any location>go to the contact information section of location click on related action of the location> choose required Usage type in Usage column>  click on related action of selected Usage type and select  Integration IDs> View IDs |
| Worker Phone Device type ID | Access View Reference IDs task in workday> search for Phone Device Type in business object box and click ok> Select the vlaue for Landline in Reference id value column. |
| Worker Mobile Phone Device type ID | Access View Reference IDs task in workday> search for Phone Device Type in business object box and click ok> Select the vlaue for Mobile in Reference id value column. |
| Worker Home Phone Communication Usage Type ID | Worker Profile> Contact Icon>  Under Home contact information tag >click on related action of "Home" Usage type in Usage coulmn in phone section and select  Integration IDs> View IDs |
| Worker Work Phone Communication Usage Type ID | Worker Profile> Contact Icon>  Under Work contact information tag  >click on related action of "Work" Usage type in Usage coulmn in phone section and select  Integration IDs> View IDs |
| Worker Home Email Communication Usage Type ID | Worker Profile> Contact Icon>  Under Home contact information tag >click on related action of "Home" Usage type in Usage coulmn in Email section and select  Integration IDs> View IDs |
| Worker Work Email Communication Usage Type ID | Worker Profile> Contact Icon>  Under Work contact information tag >click on related action of "Work" Usage type in Usage coulmn in Email section and select  Integration IDs> View IDs |
| Worker Home Address Type Reference Communication | Worker Profile> Contact Icon> Under Home contact information tag> click on related action of "Home" Usage type in Usage coulmn in Address section and select  Integration IDs> View IDs |
