## SAP - ITAM Product - Connection failed troubleshooting and other SAP common error details

  

### Summary

**Common SAP Errors or issues and their troubleshooting points.**   
  
  
**1) Servicenow SAP Test connection link is failing with error - "Request failed with response : SAMSoapHandler: Unable to generate SOAP function for SOAP Message..."**

**Workaround/Solution:** There can be different reason for this error. All possible reasons are mentioned below -

1.  WSDL is not generated by following technical documentation. Go to documentation attached at [KB0813999](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0813999) - section "Create a WSDL for your SAP service definition" -  step 8 - service name filed must be NOW\_SAMP. If generated SOAP message function name having any prefix other than ZNOW\_SAMP that means step 8 is not followed.   
2.  Multiple mid servers are present in the ecc\_agent table, and right Mid server is not selected - Please follow [KB1122513](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB1122513) for how to set mid server. 
3.   Specified mid server through which all SAP requests are reaching to SAP system is not whitelisted by customer for their targeted SAP system. Make sure with customer that mid server is whitelisted.
4.   WSDL on the sap connection is not valid. To check the validity customer can open that WSDL in their internal network, provide credentials and see if it is responding with output or not.
5.   DNS mapping is missing to resolve the IP used in the WDSL. Confirm with customer and add the right dns mapping.  
    [https://docs.servicenow.com/bundle/vancouver-servicenow-platform/page/product/mid-server/task/t\_MapIPAddressToDNSName.html](https://docs.servicenow.com/bundle/vancouver-servicenow-platform/page/product/mid-server/task/t_MapIPAddressToDNSName.html)  
      
    
6.   SAP system is taking long to respond back and hence connection time out. Increase mid server response waiting time. Follow [KB0696865](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0696865).

**2) SAP client is not received as active from SAP system to Servicenow (in the table 'samp\_sap\_client') for a SAP connection.**

**Workaround/Solution**:

1) Go to SAP system and run the /NOW/SAMP\_RFC\_DETAILS RFC program.  
2) Select required Servicenow RFC connection.  
3) Click on "Saved to Servicenow RFC List" and then click on "Test RFC Connection". RFC Connection column must have a green tick now.

Note: make sure selected theme is "Blue Crystal theme" in the SAP GUI option. 

Follow documentation steps of section "Select SAP clients to import data in your ServiceNow instance" in the page 10 (screenshot of RFC List also present in the doc for reference) - [KB0813999](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0813999)
