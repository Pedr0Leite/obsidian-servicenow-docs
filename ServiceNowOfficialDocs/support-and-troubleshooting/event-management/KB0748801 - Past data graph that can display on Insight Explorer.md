## Past data graph that can display on "Insight Explorer"

  

### Issue

# Description

Customer would like to know how long past data that "Insight Explorer" can display.

# Solution

"Insight Explorer" can display 1 year of past data.

ie: Today is 12-May-2019. The maximum past data that it can cover is between "12-May-2018" and "12-May-2019"
