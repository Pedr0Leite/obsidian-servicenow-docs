## Subflow "Password Change" is read only

  

### Issue

-   Cannot edit the "Password Change" subflow

### Cause

-   Some subflows are restricted to be modified even with the flow\_\* roles

### Resolution

1.  You can create a copy of the subflow.
2.  You should be able to modify the copy of the Flow or subflow.
