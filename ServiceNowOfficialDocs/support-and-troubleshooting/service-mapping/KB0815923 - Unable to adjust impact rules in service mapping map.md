## Unable to adjust impact rules in service mapping map

  

### Issue

When attempting to adjust impact rules for a service map in the Event Management Dashboard, the widgets to do this task are greyed out and it is not possible to modify them. They seem to be in a read-only state.

![](sys_attachment.do?sys_id=828e6441db88b4d0471f9c41ba961969)

### Release

NewYork

### Resolution

Add admin role to the user should help to fix the issue. If issue persist, please try remove browser cache.

![](sys_attachment.do?sys_id=868e6441db88b4d0471f9c41ba961966)

### Related Links

Steps to reproduce:

Navigate to Event Management Dashboard module.  
Access service map by double click tile.

Click on "Impact" button at bottom left.
