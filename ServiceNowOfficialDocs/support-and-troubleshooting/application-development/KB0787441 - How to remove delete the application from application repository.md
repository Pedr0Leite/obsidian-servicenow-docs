## How to remove / delete the application from application repository

  

### Issue

Manage your Application Repository using this self-service portal for customers:

1.  Login into instance (apprepo.service-now.com).
2.  Login with HI credential ➜ Do the Actions.

 **Note:** Delete actions are available only for "Primary Customer Admin" on the company record on HI.
