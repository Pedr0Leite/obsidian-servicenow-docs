## Content Editor does not allow hyperlinks in bullet lists

  

### Issue

The Rich Content Editor's bullet list block does not allow creating hyperlinked words; hyperlinks only work in simple text blocks.

### Release

Any Release

### Cause

This is the current design of the List component. Hyperlinking in rich content bulleted lists is not currently supported as a standard feature.

### Resolution

**Steps to Resolve**  
1\. Use the 'edit code' feature to customize the HTML and manually add hyperlinks to bullet point text.  
2\. Refer to the Edit code documentation for reference: https://www.servicenow.com/docs/bundle/washingtondc-employee-service-management/page/product/employee-center/concept/ec-rich-content.html  
3\. Note that hyperlinking in rich content bulleted lists is a new feature being built and will be available in the next release.
