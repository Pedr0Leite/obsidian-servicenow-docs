## Case Creation Page

The Case Creation Page is a dedicated interface in the HR Agent Workspace, designed to simplify case creation by presenting relevant information in a step-by-step format. This page, exclusively available in the HR Agent Workspace, acts as an interceptor for creating new cases efficiently.

## Contextual Sidebar Page

The Contextual Sidebar Page in HR Agent Workspace adapts dynamically to records, displaying different tabs based on specific conditions. This flexibility enables customization of tabs, configurations, and content visibility to suit varying use cases.

-   [Contextual sidebar page overview (KB1709944)](/kb?id=kb_article_view&sysparm_article=KB1709944)

## Record Page

The Record Page in the HR Agent Workspace provides a streamlined view for interacting with individual records. It organizes key information, related tasks, and contextual tools in a centralized layout, enhancing efficiency and user experience for agents managing HR cases.

-   [Record page overview (KB1707028)](/kb?id=kb_article_view&sysparm_article=KB1707028)
