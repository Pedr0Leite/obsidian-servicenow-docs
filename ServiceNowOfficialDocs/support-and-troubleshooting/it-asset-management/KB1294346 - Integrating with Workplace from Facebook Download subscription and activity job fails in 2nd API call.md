## Issue

Datastream actions "**Look up Organization Members Stream**" and "**Look up conversation stream**" may fail after the second API call. The outbound HTTP log shows http 500 internal server error.

## Resolution

Download and install the attached [Facebook Workplace Fix update set](sys_attachment.do?sys_id=295e21504740bd1011eaf24c736d4373 "Facebook Workplace Fix").
