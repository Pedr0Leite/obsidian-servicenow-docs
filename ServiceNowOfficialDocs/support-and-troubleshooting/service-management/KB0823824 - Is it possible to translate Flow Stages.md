## Issue

How to translate the Flow Stages so that they are displayed in the language of the end user, similar to how it is done with Workflows:

[https://docs.servicenow.com/csh?topicname=add-translate-stages.html&version=latest](https://docs.servicenow.com/csh?topicname=add-translate-stages.html&version=latest)

## Resolution

This is expected behaviour, this functionality is not present today in Flow Designer. 

You can submit this request on the idea portal providing the necessary business/technical justification and impact of this requirement:  
[https://support.servicenow.com/kb\_view.do?sysparm\_article=KB0755878](https://support.servicenow.com/kb_view.do?sysparm_article=KB0755878)
