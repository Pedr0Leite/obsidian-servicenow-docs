## When attempting to use the "Printer-friendly version" (in System settings) for printing HR Cases, Additional comments/work notes are not coming over

  

### Issue

-   When the user is attempting to use the System settings "Printer-friendly version" for printing out their HR Cases, the Additional comments/work notes fields are not coming over. 

### Resolution

1.  This is the Out of Box, designed behavior, and has been tested across multiple browsers to ensure it has nothing to do with browser configuration
2.  It is recommended that the user should use the "Export to PDF" functionality and then print the PDF which will have the Additional comments and/or work notes present.
