# Enable the Now Assist Panel (K26 SNU8139 lab walkthrough)

1. Navigate to **Conversational Interfaces > Assistant Designer**.
2. Press **Get started** to close the Welcome pop-up.
3. Select the **Edit** button in the **Now Assist Panel - Platform (default)** tile.
4. Once the **Overview** page loads, select **Go to display experiences** link.
5. Expand the **Add ServiceNow platform** dropdown and select **United Navigation app shell**.
6. Press **Add**.
7. Save the Now Assist Panel configuration by pressing **Save**.
8. Once the configuration is saved, press the **Activate** button.
9. Navigate to **Now Assist Admin > Experiences**.
10. Press the **Turn on** button to enable fulfillers and admins to use the **Now Assist Admin** panel.

The **Now Assist Panel** conversational assistant has been activated and is ready to be used.
