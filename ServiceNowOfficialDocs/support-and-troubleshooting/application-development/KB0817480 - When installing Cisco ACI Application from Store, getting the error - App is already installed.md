## When installing "Cisco ACI Application" from Store, getting the error - "App is already installed"

  

### Issue

-   When trying to install the Application - "Cisco ACI Application" it is throwing the error "App is already installed"
-   This error is encountered while trying to install the Application via the STORE

### Resolution

-   The "Cisco ACI Application" is also available from System Applications - ALL
-   Installed the Application from System Applications - ALL
-   Application installed successfully
