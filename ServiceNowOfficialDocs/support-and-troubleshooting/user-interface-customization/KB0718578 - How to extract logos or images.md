## Issue

# Description

* * *

There may be times where customers need to extract an image within ServiceNow from a logo, to an embedded image within an article.

# Procedure

* * *

There are 2 ways to extract an image.

-   Right-click and select "save image as", save the image as the default iix extension and then rename to png or jpg etc depending on the format of the file
-   Right-click and "Inspect" the page. Select the image, it will appear in the format sys\_id.iix. Then search for the sys\_id on the sys\_attachments table.

# Applicable Versions

* * *

Any
