## Issue

"CloudFoundry" pattern that is new to the Discovery and Service Mapping store application failing with below errors:

Identification Engine: Discovery status is FAILURE, Identification sections in pattern failed: section: identification, error: Reference and relation tables must be a CI Type, change cmdb\_ci\_pcf\_appl to a correct type

## Resolution

This Cloudfoundry Application is available from 1.0.49 version. It is not available for the previous versions.
