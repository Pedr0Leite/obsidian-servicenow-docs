## Configuring and synchronizing ServiceNow with Azure AD

  

### Issue

This article describes how to configure Azure Active Directory single sign-on (SSO) integration with ServiceNow with user provisioning.

This AAD SSO Integration was made and managed by Microsoft.

### Release

All

### Resolution

Please follow the documentation provided by Microsoft to achieve this:

-   [Tutorial: Azure Active Directory single sign-on (SSO) integration with ServiceNow](https://docs.microsoft.com/en-us/azure/active-directory/saas-apps/servicenow-tutorial "Tutorial: Azure Active Directory single sign-on (SSO) integration with ServiceNow")
-   [Tutorial: Configure ServiceNow for automatic user provisioning](https://docs.microsoft.com/en-us/azure/active-directory/saas-apps/servicenow-provisioning-tutorial "Tutorial: Configure ServiceNow for automatic user provisioning")
