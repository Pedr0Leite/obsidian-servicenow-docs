## \[SAMP\\License Key\] Feasibility to track the License key of a Product

  

### Summary

-   For any assets created via Software Entitlement import is there any automated way in ServiceNow to detect the License Key information of the Product.

### Release

-   Instance with SAMP plugin enabled.

### Instructions

-   ServiceNow do not have any automated feature to obtain the License Key information of a Product using SAMP OOTB.
-   But the License Key information can be tracked, by manually inputing the License Key information of a Product during Software Entitlement import (or) **navigating >> Software Entitlement** and open any entitlement and under the Related Links "License Keys" tab, you can fill in License Keys manually.
