## Issue

Why does 'Windows Installed Software' probe throw error "Unhandled Exception: System.AccessViolationException: Attempted to read or write protected memory. This is often an indication that other memory is corrupt.at System.Management.IWbemServices"?

## Resolution

This behaviour is not observed with **.Net version 4.7**.
