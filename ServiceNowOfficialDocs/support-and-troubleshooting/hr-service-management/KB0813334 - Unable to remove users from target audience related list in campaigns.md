## Unable to remove users from target audience related list in campaigns

  

### Issue

Once users get added to Campaign Target related list, are always a part of Campaign.  
If Audience condition gets changed, new set of Users are getting added but users no more satisfying the condition are not getting removed from the Campaign Target related list.

### Resolution

In NY we can only add users to campaign, removing user feature is available from Orlando release.

Since this is a feature enhancement going available from Orlando, we do not have any Workaround for it.
