## Issue

**SNC.CanonicalName.normalizeCompany(companyName, false)** function which is called in "**Canonicalize Manufacturer Company CI**" Business Rule returns an inconsistent company name if "**glide.cmdb.canonical.company.enabled**" sys\_properties record is set to **false**. 

This behaviour can be observed, if there are 2 core\_company records with the same string but with different letter cases: 

**1ABC** core\_company record. 

**1Abc** core\_company record. 

When you change a configuration item's manufacturer value to '**1ABC**', it can occur that the manufacturer value is set to "**1Abc**". 

## Resolution

Setting "**glide.cmdb.canonical.company.enabled**" sys\_properties record to **true**
