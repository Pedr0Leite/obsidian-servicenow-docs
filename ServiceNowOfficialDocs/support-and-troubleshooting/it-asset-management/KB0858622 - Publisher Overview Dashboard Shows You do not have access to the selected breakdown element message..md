## "Publisher Overview" Dashboard Shows "You do not have access to the selected breakdown element" message.

  

### Issue

SAMP "Publisher Overview" Dashboard Shows "You do not have access to the selected breakdown element" message for VMware, IBM and Oracle Publisher Packs.

![](/sys_attachment.do?sys_id=c290410347218fd83542f24c736d43e6)

### Release

ALL

### Resolution

1)Login to [https://<instancename>.service-now.com/](https://krishchai.service-now.com/)

2)Navigate to Software Publishers table and search for the effected Publisher Pack like Oracle.

[https://<instancename>.service-now.com/samp\_sw\_publisher\_list.do](https://krishchai.service-now.com/samp_sw_publisher_list.do)

3)Make sure 'Use when reporting' field is set to true for the Software Publisher.
