## PowerShell error "A connection to the directory on which to process the request was unavailable. This is likely a transient condition."

  

### Issue

Users may encounter the following error while running PowerShell commands to orchestrate with Active Directory (AD).

"A connection to the directory on which to process the request was unavailable. This is likely a transient condition."

The error is reproduced when implementing a workflow that triggers up to 20 PowerShell sessions to run, each importing the Active Directory module to create a connection with AD.

### Facts

Active Directory enforces a restriction on the number of concurrent connections it can handle. As a result, some connection requests fail, leading to the PowerShell execution errors observed.

### Release

All

### Cause

This error occurs when multiple AD PowerShell sessions attempt to connect concurrently, each importing the Active Directory module. This typically results in transient failures when the AD server or domain controller cannot accommodate the connection volume in a short period of time (~20 requests or more).

### Resolution

To address this, we recommend collaborating with your Active Directory and infrastructure teams to review and adjust the connection concurrency settings, ensuring that the AD environment is optimized to handle the load generated by the orchestration workflows. 

Additionally, review any flows or logic triggering simultaneous PowerShell connections. Consider staggering execution or reworking the orchestration to reduce the load sent to Active Directory.
