## Issue

A **Not Authorized** message appears when selecting **Create New Server** in the System Lightweight Directory Access Protocol (LDAP) application.

![LDAP application window with Create New Server selected in the left column and Not Authorized message in the right column](/sys_attachment.do?sys_id=d0faece6db42b450e515c223059619e7 "System LDAP application window")

## Resolution

1.  Navigate to **Service Catalog > Record Producers**.
2.  Search for and select the **New LDAP Server** record.
3.  Set record to **Active**.
