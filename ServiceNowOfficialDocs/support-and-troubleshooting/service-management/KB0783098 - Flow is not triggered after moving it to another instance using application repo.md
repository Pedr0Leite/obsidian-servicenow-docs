## Flow is not triggered after moving it to another instance using application repo

  

### Issue

Flow is not triggered after moving it to another instance using application repo

### Release

Madrid Patch 7

### Resolution

Moving flow designer using app repo is not fully supported yet. Instead, the flow can be moved using an "Update Set" and it should fix the issue
