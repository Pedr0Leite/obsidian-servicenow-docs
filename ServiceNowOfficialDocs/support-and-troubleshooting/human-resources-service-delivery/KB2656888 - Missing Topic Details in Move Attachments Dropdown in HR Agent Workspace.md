## Missing Topic Details in Move Attachments Dropdown in HR Agent Workspace

  

### Issue

When using Move Attachments in HR Agent Workspace (Configurable), not all Topic Details are displayed in the dropdown, making some options unavailable. The issue does not occur in Classic UI or Legacy Workspace.

### Release

Any

### Cause

Product defect affecting dropdown population for Topic Details in Move Attachments feature.

### Resolution

-   Upgrade to HR Agent Workspace v3.2.1 (Nov 2024 Patch) or later to apply the fix.
-   Track PRB1780778 for reference.
