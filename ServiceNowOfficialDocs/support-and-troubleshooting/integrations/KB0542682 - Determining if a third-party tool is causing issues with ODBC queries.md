## Determining if a third-party tool is causing issues with ODBC queries

  

### Issue

Determining if a third-party tool is causing issues with ODBC queries

Symptoms

* * *

-   Query returns no records
-   Query results in no data returned

   
Cause

* * *

If you are querying from a tool not listed in product documentation (iSQL, MS SQL Server, Crystal Reports), then your third-party tool may be causing the issue.

Resolution

* * *

Try running the same query from the iSQL console.
