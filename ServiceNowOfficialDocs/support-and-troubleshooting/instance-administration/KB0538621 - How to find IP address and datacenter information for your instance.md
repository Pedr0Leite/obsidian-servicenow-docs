## How to find IP address and datacenter information for your instance

  

### Issue

Find the IP address and datacenter information for the ServiceNow instances you manage. ServiceNow provides an automated workflow in the Now Support Automation Store for customers and partners to obtain this information at any time.

### Release

All supported releases

### Resolution

1.  Go to [Now Support](https://support.servicenow.com/now).
2.  Select **Automation Store**.
3.  Go to **All Automations** > **Service Catalog** > **Instance Management** and select **My IP Information**.
4.  Select the instance.
5.  Select **Submit**.
6.  The IP address and datacenter information for the instance is displayed.
