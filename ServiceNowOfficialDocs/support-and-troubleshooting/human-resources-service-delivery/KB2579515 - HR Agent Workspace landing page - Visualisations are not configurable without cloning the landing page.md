## Issue

In the configurable HR Agent Workspace landing page, the  'Carousel' component is designed to be configurable; however, visualisations such as 'High Priority Cases' scorecards are not configurable unless the landing page is cloned and the data source is modified in the UI Builder.

![](/sys_attachment.do?sys_id=1c31a97893057298def533527cba10de)

## Resolution

To configure the visualisations, you’ll need to clone the out-of-the-box (OOTB) landing page and apply the necessary changes through the UI Builder.

We are planning to make these visualisations configurable—similar to the Carousel component—in a future release, although the timeline for this enhancement is yet to be confirmed.
