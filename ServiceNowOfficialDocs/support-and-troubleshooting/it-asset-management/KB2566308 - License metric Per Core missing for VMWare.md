## Issue

When creating a new VMWare software entitlement, the "Per Core" license metric isn't available

## Resolution

The per core license metric under VMware metric group would be available to public only from Zurich. Since it is a new feature that is being shipped, customers would have to upgrade to Zurich to utilize this core metric.
