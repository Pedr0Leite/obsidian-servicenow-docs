## ServiceNow Add-in for Microsoft Outlook does not initiate the Virtual Agent Chat from outlook Web Access

  

### Issue

ServiceNow Add-in for Microsoft Outlook does not initiate the Virtual Agent Chat from outlook Web Access

### Cause

ServiceNow Add-in for Microsoft Outlook is not supported on Microsoft Outlook Web Client

### Resolution

Microsoft Outlook for Windows and Microsoft Outlook for Mac are the only supported clients.
