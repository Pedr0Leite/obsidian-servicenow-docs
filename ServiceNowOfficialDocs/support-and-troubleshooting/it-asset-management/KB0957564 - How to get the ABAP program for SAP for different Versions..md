## How to get the ABAP program for SAP for different Versions.

  

### Summary

Establishing a connection between SAP system and ServiceNow instance, we need to deploy the Advanced Business Application Programming (ABAP) program.

To access the ABAP program, download the SAP ABAP for Software Asset Management app on the ServiceNow Store.

  

[https://store.servicenow.com/sn\_appstore\_store.do#!/store/application/e1e9a2f6dbdc141079279ee4db96195d/3.0.0](https://store.servicenow.com/sn_appstore_store.do#!/store/application/e1e9a2f6dbdc141079279ee4db96195d/3.0.0)

### Release

From 'Orlando'

### Instructions

1.) Login to "[https://store.servicenow.com/](https://store.servicenow.com/)"

2.) Search for "SAP ABAP Program for Software Asset Management"

3.) Click on "Other App Versions" as shown in below screenshot.

  

![](/sys_attachment.do?sys_id=48fb3f69dbc728107d3e02d5ca9619fe)

4.) Select the required version and click on 'view details' which will route it to corresponding downloadable files as shown in below screenshot.
