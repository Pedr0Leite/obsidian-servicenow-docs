## Fix multi-row variables not showing on requested items from Service Portal

  

### Issue

Multi-row variable set values may not display in the requested item (RITM) variable editor when submitted through Service Portal. 

### Release

Any supported release

### Cause

This issue could be due to using a deprecated Service Catalog item widget instead of the default widget. 

### Resolution

To display multi-row variable set values correctly, use the current default Service Catalog item widget.
