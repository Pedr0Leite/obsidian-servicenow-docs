# Customizing Text in the Now Assist Chat Window

## Issue

Pedro attempted to change a label/message in the Now Assist (Virtual Agent) chat window by editing the value of a `sys_ui_message` record, but the change was not reflected in the chat window.

## Investigation

- ServiceNow support verified the `sys_ui_message` value change was not propagating to the Virtual Agent chat text.
- Deleting and recreating the record did not resolve it.
- Creating a new record scoped to Virtual Agent also did not resolve it.
- The behavior was reproduced on an out-of-the-box **Australia release** instance, but the same customization worked as expected on a **Zurich release** instance — i.e., this is a release-specific regression/behavior change.

## Root Cause

On the Australia release, the Now Assist disclaimer text in the chat window does not pick up a standard `sys_ui_message` override the way it did in Zurich.

## Solution

ServiceNow's internal team identified a workaround specific to the Australia release:

1. Open (or create) the relevant `sys_ui_message` record.
2. In the **Code** field, set the value to:
   ```
   nass-default-disclaimer-message
   ```
3. Put the desired custom text in the **Message** field.
4. This causes the system to use the custom message instead of the default Now Assist disclaimer text.

ServiceNow support applied this change directly on the instance and confirmed the issue was resolved.
