## ServiceNow-Jira Integration Issue- Mid Server selection option not seen in JIRA Spoke integration page

  

### Issue

Issue :

Customer could not find an option to select the MidServer that they want for the JIRA Spoke integration from the below HTTPs connection page though� it gives an option to select Mid Server :

![](sys_attachment.do?sys_id=41f41c8ddb00b8d066e0a345ca96190a)

### Release

NA

### Cause

NA

### Resolution

Solution :

Users cannot select a MID server but the appropriate MID server will be picked up at the runtime based on the Capabilities & MID Application fields in the Advanced MID Server Configuration section in the HTTP(s) Connection form.
