## Issue

**Detailed IP address information** for any of your instances can be found by using the **Now Support Service Catalog.**

Navigate to the **Automation Store ► Service Catalog ► Instance Management** and select the item called [My IP Information](https://support.servicenow.com/now?id=ns_automation_store "My IP Information"). After finding the instance name in the drop-down menu and clicking **Submit**, a report will be generated where you will find the following information:

-   VPN Peer IP Address
-   The source address used for integrations into customer network with NO VPN
-   The source address used for integrations into customer network with VPN
-   The address to which your instance resolves.
-   The instance's geographic location

You can repeat this process as needed for the rest of your instances as well.
