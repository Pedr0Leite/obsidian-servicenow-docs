## Issue

Unable to automatically create a PDF document automatically on a HR document template as explained in docs here:  
[https://docs.servicenow.com/bundle/paris-hr-service-delivery/page/product/human-resources/task/task-mapped-participants.html](https://docs.servicenow.com/bundle/paris-hr-service-delivery/page/product/human-resources/task/task-mapped-participants.html)  
[https://docs.servicenow.com/bundle/paris-hr-service-delivery/page/product/human-resources/concept/generate-pdf-doctemp.html](https://docs.servicenow.com/bundle/paris-hr-service-delivery/page/product/human-resources/concept/generate-pdf-doctemp.html)  
  
because the "Automatically Initiate Document task"s case option does not exist.

## Resolution

To fix the issue, install this plugin.

  
NOTE: The plugin gets installed automatically for customers having Human Resources Scoped App: Lifecycle Events for Enterprise plugin.  
  
Refer the documentation for more details - [Activating Plugin](https://docs.servicenow.com/bundle/paris-hr-service-delivery/page/product/human-resources/concept/understanding-doc-templates.html#understanding-doc-templates "Activating Plugin")
