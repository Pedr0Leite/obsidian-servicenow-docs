## "List - Dashboard" view mode is not working

  

### Issue

**List - Dashboard** view mode is not working. It seems like the button is not active, as when Bubbles or Tile view mode is on, nothing happens when the button is pressed.

### Resolution

Please try to resolve the issue: 

1.  Try using another browser, or clear the browser's cache and try again.
2.  Update Flash Player version.
