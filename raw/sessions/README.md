# Sessions

Auto-captured Claude Code session logs, written by `~/.claude/claude-memory-compiler`'s `SessionEnd`/`PreCompact` hooks (global, fires for any project). One file per day: `YYYY-MM-DD.md`. Raw layer — immutable once written, compiled into `wiki/` by `compile.py`.

Distinct from `logs/` (vault root): that's the manual, curated `/save` log. This folder is automatic and unreviewed until compiled.
