## User is showing 'Cleared' Requirement status when they are not in the Audience for that Requirement

  

### Issue

A **Health & Safety User** is showing their **Requirement status** as **'Cleared'** but they are **not** in the **Audience** for that **Requirement**.

### Cause

This is actually the **expected system behaviour** since it will prevent the User from getting stuck in the **'Not Cleared' Requirement status** when they have been **Cleared** for all **Requirements** in their **Audience**.

### Resolution

Please be assured that it is **expected behaviour** for the **User** to be **cleared** for **Requirements** which they are **not** in the **Audience** for.

If the User is added to the **Audience** then the behaviour will continue as expected.
