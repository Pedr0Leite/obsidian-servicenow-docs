## Issue

-   Although the catalog item is published, a user with sn\_cmp.cloud\_service\_user and cloud\_user role cannot see items in cloud portal catalog.

## Resolution

-   An entry should exist for the catalog item and the user group defined.
-   Create a permission entry for the user group with the catalog item.
