## After importing a new map users are not getting auto populated on the map

  

### Issue

Users are not getting auto-populated in a new building after importing a new map.

### Release

Kingston Patch 7

### Cause

Micello gave each geoJSON file a different name.

### Resolution

Verify that Micello gives each geoJSON file the same name.
