## List of currently supported Amazon AWS EC2 Instance types in CMP/Cloud Discovery

  

### Issue

List of currently supported Amazon AWS EC2 Instance types in CMP/Cloud Discovery

Below is the list of currently supported Amazon AWS EC2 Instance types (Hardware Types) in CMP and Cloud Discovery. As of today, any other hardware types are not supported at this stage, for example, the "m5" series AWS EC2 Instance types.

If you do need to use the unsupported Hardware Types, the workaround is to manually create custom Hardware Types and then use them in CMP/Cloud Discovery.
