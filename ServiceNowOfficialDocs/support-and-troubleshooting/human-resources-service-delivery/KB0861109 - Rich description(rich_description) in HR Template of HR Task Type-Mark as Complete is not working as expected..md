## Rich description(rich\_description) in HR Template of HR Task Type-Mark as Complete is not working as expected.

  

### Summary

Rich description(rich\_description) in HR Template of HR Task Type-Mark as Complete is not working as expected. It gets rendered as tags in the Portal view

### Instructions

-   Rendering of rich\_description is happening as expected in the platform view but not on the portal view.
-   OOB HR portal widget used for "HR Task Type-Mark as Complete" is "HRJ Task Mark As Complete" and check if its customised.
-   Reverting the widget to OOB version should resolve the issue.
