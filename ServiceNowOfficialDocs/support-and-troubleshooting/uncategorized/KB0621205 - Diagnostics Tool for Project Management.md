## Diagnostics Tool for Project Management

  

### Issue

Project Management | Diagnostics Tool  

  
  

# Overview

* * *

A diagnostics tool is available that validates and prints a report on project structure integrity.

The attached update set (named sys\_remote\_update\_set\_f7aca70d37022200af1326877e41f130.xml) adds a new UI action named **Project Diagnostics** to the Project record. The UI action appears only if the logged in user has the **admin** role.

![](sys_attachment.do?sys_id=c9fa202adb42b450e515c223059619d8)

Load the customization into the instance. For detailed information, see [Load a customization from a single XML file](https://docs.servicenow.com/csh?topicname=c_ApplicationTools.html&version=latest "Load a customization from a single XML file").
