## Automatic Reply Email sent only once to the instance

  

### Summary

Automatic Reply (out of the office) emails are not sent to the Instance all the time when any notification is sent to the user from the Instance. 

Automatic Reply is being sent only once from the outlook. This is expected behaviour as per Microsoft.
