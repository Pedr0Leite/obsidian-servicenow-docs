## Issue

# Description

With Software asset management premium/professional(SAMP), we allow the software model to be created in two ways :   
Option 1 : From an entitlement where you can specify a publisher part number and the software model gets created for you.   
Option 2 : Create the software model yourself from the Software Model Module.   
  
We do not support the use case of create a Software Model from a Discovery Model in SAMP but you can always view the related discovery models for a software model by using the form link "Show Matching Discovery Models" on the Software model form.
