## ITAM License Report not available on filter navigator

  

### Summary

Search for 'ITAM License Report' tab under filter navigator.

This page will be available under ITAM Licensing.

URL for this page:- https://instancename.service-now.com/itam\_licensing\_resource\_counts\_list.do?sysparm\_query=&sysparm\_view=

Customer can open this page by typing the ULR on the browser but it's NOT visible from filter navigator.

Related article: https://docs.servicenow.com/bundle/quebec-it-asset-management/page/product/hardware-asset-management/task/view-itam-license-sum.html.

### Instructions

**Solution Proposed:** \[/code\]  
\[-\] Please edit the ITAM Licensing tab using pencil icon on the right side of the filter navigator  
OR  
Goto below link  
https://InstanceName.service-now.com/nav\_to.do?uri=sys\_app\_application.do?sys\_id=e365905185411010fa9b021697d33389

\[-\] make ITAM License Report tab active

![](sys_attachment.do?sys_id=05b5468edb85e9d0e3a1c4be139619e2)

\[code\]

Note: If there is no issue with above it could be Plugin issue. Work further to investigate.
