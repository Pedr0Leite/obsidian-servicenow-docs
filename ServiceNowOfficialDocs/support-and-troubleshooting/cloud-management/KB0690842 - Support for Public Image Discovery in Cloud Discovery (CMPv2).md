## Support for Public Image Discovery in Cloud Discovery (CMPv2)

  

### Issue

# Description

* * *

When using 'Cloud Discovery' a very common question is discovery of public images using the CMPv2 discovery module.

Whereas **[AWS and Azure cloud discovery](https://docs.servicenow.com/csh?topicname=r-discovery.html&version=latest "AWS and Azure cloud discovery")** discovers the private images created on the respective AWS and Azure subscriptions, the public image discovery is not supported.  
  

# Procedure

* * *

This article describes the process for adding a public image to a ServiceNow instance via the [Resource Profiles](https://docs.servicenow.com/csh?topicname=cloud-resource-profiles.html&version=latest "Resource Profiles").  
  

-   The procedure for adding AWS public images to cmdb\_ci\_os\_template can be found in the below document:  
      
    -   [Add an AWS public image to Cloud Management](https://docs.servicenow.com/csh?topicname=add-public-image-aws.html&version=latest "Add an AWS public image to Cloud Management")  
          
        
-   The procedure for adding Azure public images to cmdb\_ci\_os\_template can be found in the below documents:  
      
    -   [Add an Azure public image to Cloud Management](https://docs.servicenow.com/csh?topicname=add-public-image-azure.html&version=latest "Add an Azure public image to Cloud Management")
    -   [Generic Process for Azure](sys_attachment.do?sys_id=350ca02edb42b450e515c223059619e2 "[Generic Process for Azure]")  
          
        

# Applicable Versions

* * *

Jakarta and above.
