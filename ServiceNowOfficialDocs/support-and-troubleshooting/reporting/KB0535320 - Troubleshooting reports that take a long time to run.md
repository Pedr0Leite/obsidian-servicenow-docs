## Troubleshooting reports that take a long time to run

  

### Issue

Troubleshooting reports that take a long time to run

  
Details  

* * *

This article provides information on why reports may take a long time to run and how to address the issue.

  
  
Resolution  

* * *

If your report is taking a long time to run, some common causes and possible solutions include: 

1.  How large is the table? If the user is reporting off of a large table, the report takes much longer to return results based on the data size.
2.  Verify that the report is optimized as efficiently as possible. Check the filter conditions and turn on SQL debug for assistance.
