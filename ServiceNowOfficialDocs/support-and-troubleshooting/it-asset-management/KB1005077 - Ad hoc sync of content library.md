## Ad hoc sync of content library

  

### Issue

-   Ad hoc sync of content library  
      
    
-   We may receive requests from the customer to help with the steps to run the Content Library sync on an instance on the ad hoc basis.

### Release

-   All

### Resolution

-   Login to the instance  
      
    
-   Navigate to the table "cds\_client\_schedule"  
      
    
-   Execute all the jobs listed under the above table  
      
    _**Please note, there is NO sequence while running the above jobs but make sure that all the jobs are executed/run.**_
