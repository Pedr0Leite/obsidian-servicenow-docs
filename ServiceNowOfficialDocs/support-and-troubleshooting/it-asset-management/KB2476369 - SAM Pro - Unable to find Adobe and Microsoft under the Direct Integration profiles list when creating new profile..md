## SAM Pro - Unable to find Adobe and Microsoft under the Direct Integration profiles list when creating new profile.

  

### Issue

Unable to find Adobe and Microsoft under the Direct Integration profiles list when creating new profile.

### Release

Any Version

### Cause

This is happening because of missing files from the software asset management - SaaS License Management plugin.

### Resolution

1.  To fix this, we need to repair/reinstall the software asset management - SaaS License Management plugin.
2.  If plugin repair is failing, please raise a case with Service Now support.
3.  We need to perform a few steps from the support end to fix this. Only the user with the "Maint role" should be able to do this.
