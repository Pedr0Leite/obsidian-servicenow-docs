## Issue

  

Overview

* * *

This article provides additional details about the security settings and plugins that must be configured properly or enabled on ServiceNow instances in order to be eligible to be in the FedRAMP environment. The Potential Impact is what may result from configuring or enabling them. The Potential Security Risk is the risk associated with each item if it is not properly configured. These settings are specific to "fedramp Instance Hardening", which is a subset of the complete instance hardening guide in [KB0550654: ServiceNow Security Instance Hardening](/kb_view.do?sysparm_article=KB0550654 "KB0550654").
