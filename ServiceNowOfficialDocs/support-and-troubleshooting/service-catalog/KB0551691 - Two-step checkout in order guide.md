## Two-step checkout in order guide

  

### Issue

Two-step checkout in order guide 

Overview

* * *

By default, order guides present the customer with a three-step ordering process:

1.  **Describe Needs:** Enter information as prompted. Order guide [rules](https://docs.servicenow.com/csh?topicname=t_CreateARule.html&version=latest "rules") evaluate this information to determine which catalog items to order.
2.  **Choose Options:** Select configuration options for the ordered items and provide any additional information needed.
3.  **Check Out:** Review and edit item information, then click **Submit Order** to place the request.

Description

* * *

When the **Two step** option in order guide is selected, the **Check Out** step is omitted to provide a quicker two-step process. Therefore, when clicking on **Checkout** in the order guide, the request is submitted immediately and the order confirmation screen is displayed.

For more information, please refer to [Service Catalog Order Guides](https://docs.servicenow.com/csh?topicname=c_ServiceCatalogOrderGuides.html&version=latest "Service Catalog Order Guides").
