## Issue

This article describes how to identify the affected transaction by node and how to provide relief by disabling (killing) the transaction.

**Note**: This activity can only be completed by users with the '_**admin**_' role

## Resolution

To View active transactions:

-   -   Navigate to **System Diagnostics > Active Transactions** (All Nodes).
    -   Select the transaction to kill.
    -   Check the check box beside the record, and then select **Kill** from the choice list.
