## Integration Hub over-allocation caused by Microsoft Azure AD Download Group Memberships job

  

### Issue

When using the Microsoft Azure AD spoke, the "Download Group Memberships" scheduled job generates a high number of Integration Hub API calls, resulting in over-allocation of Integration Hub usage.  
  

### Release

All

### Cause

The high number of API calls is caused by the "Microsoft Azure AD - Download Group Memberships" scheduled job, which is part of the SSO integration with Azure AD for the SAM product.

The "Look up Group Membership Stream by Directory" action is triggered by this scheduled job. Because this action pulls in the group memberships for each SSO group individually, the total number of API calls is determined by the number of groups configured in the directory integration profile. For example, 15,000 groups in the directory integration profile result in at least 15,000 API calls. This is the expected behavior of the action.

### Resolution

-   Review the directory integration profile to confirm the total number of groups configured, as this determines the minimum number of API calls generated by the job.
-   There is no default functionality to reduce the number of API calls made by the Microsoft Azure AD - Download Group Memberships job. This behavior is by design.
-   If a reduction in API calls is required, submit an enhancement request through the standard ServiceNow enhancement process.
