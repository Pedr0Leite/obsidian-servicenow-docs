## Issue

Create a Software Model and shows Suite Components and Suite Parents while creating the model. As user saves the record these 2 tabs disappear.

This is happening for few Software Model.

  

  

![](sys_attachment.do?sys_id=27608f64db5fac506621d9d9689619b0)

## Resolution

This is expected behavior and is happening due to UI Policy  
Customer can customize this behaviour, changing UI Policy is one way or updating product setting as shown in image above.
