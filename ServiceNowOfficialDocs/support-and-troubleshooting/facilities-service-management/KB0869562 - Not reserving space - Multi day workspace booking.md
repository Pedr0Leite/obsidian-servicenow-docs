## Not reserving space - Multi day workspace booking

  

### Issue

Not reserving space - Multi day workspace booking

### Resolution

That is the expected out-of-the-box behavior. Multi-day reservations offer a "Space preference" field and allow users to pick ANY reservable space. If the space is available for the selected time block(s), and if the request is approved, the reservations will be made. If there is a conflict, the request will go into a Pending state and the Workplace Manager will have to create the reservations.
