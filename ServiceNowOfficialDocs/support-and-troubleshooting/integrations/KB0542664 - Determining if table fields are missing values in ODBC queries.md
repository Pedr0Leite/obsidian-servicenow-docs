## Determining if table fields are missing values in ODBC queries

  

### Issue

Determining if table field is missing values in ODBC queries  
 

Symptoms

* * *

-   Query returns column names but not values
-   Query returns no values

   
Cause

* * *

The table field does not have values.

Resolution

* * *

Make sure that the field you have queried has values. Log in to the instance through the UI to add values.
