## Using the Avaya IP phone in Discovery

  

### Issue

Although there are no included probes for the Avaya IP phone, if it uses SNMP, you can create your own probes to collect the data you want.

1.  Navigate to **Discovery Definition > Probes** and click **New**.
    
2.  Consult the product documentation topic [Example: populate a CI with text file values using a custom Discovery probe](https://docs.servicenow.com/csh?topicname=t_CustomProbeTextFile.html&version=latest "Example: populate a CI with text file values using a custom Discovery probe").
