## When clicking on the "Reference qual condition" filter on the "Lookup select box" variable, there is an error message

  

### Issue

# Symptoms

* * *

When clicking on the "Reference qual condition" filter on the "Lookup select box" variable, there is an error message

# Release

* * *

Kingston

# Cause

* * *

The field "Reference qual condition" is not intended to be used with the "Lookup select box" type variable.

# Resolution

* * *

The field "Reference qual condition" is not intended to be used with the "Lookup select box" type variable.

Instead, we could use the "Reference qual" field, where we can specify the reference qualifier.

Please refer to the section "Advanced reference qualifier" in this documentation,

[https://docs.servicenow.com/csh?topicname=c\_ReferenceQualifiers.html&version=latest](https://docs.servicenow.com/csh?topicname=c_ReferenceQualifiers.html&version=latest)
