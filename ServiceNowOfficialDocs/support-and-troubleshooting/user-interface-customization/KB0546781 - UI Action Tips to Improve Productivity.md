## UI Action Tips to Improve Productivity

  

### Issue

This document provides practical tips for creating and using UI actions effectively.

UI actions simplify processes and guide user activity on forms and lists. Well-designed UI actions come from thinking about the function from a user perspective and applying a few clear guidelines. This article explains how to design and implement UI actions to improve usability and consistency.

### Release

  All Releases

### Resolution

### Tip #1: Design user-friendly UI actions

-   Use defaults that reflect the most likely or safest user choice.
-   Place primary and secondary actions appropriately to indicate importance.
-   Keep the look and function of UI actions consistent across the platform.

### Tip #2: Give each UI action a clear name

-   Use distinct and meaningful names.
-   A clear action name organizes the list and makes actions easy to find.

### Tip #3: Apply conditions when needed

-   Add conditions to control when an action executes.
-   This prevents unnecessary clutter and ensures actions appear only when relevant.

### Tip #4: Use buttons, menus, and links effectively

-   Buttons: Use for frequently used actions. Limit to 4–5 per form. Keep labels short (max. 25 characters).
-   Links: Use when button names would be too long or when reducing button clutter.
-   Menus: Place less frequently used actions in menus, such as administrative options.

### Tip #5: Use business rules for logic

-   Keep UI actions simple by delegating logic to business rules.
-   This improves debugging and makes logic reusable elsewhere in the system.

### Tip #6: Reuse logic with script includes

-   Use script includes for complex or repeated logic.
-   This makes your code more scalable, testable, and easier to manage.
