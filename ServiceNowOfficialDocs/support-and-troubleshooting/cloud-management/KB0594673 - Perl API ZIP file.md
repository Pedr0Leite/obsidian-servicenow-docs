## Issue

The Perl API provides a library of Perl classes and sub routines for programmatic access to the platform and its applications. The API utilizes the SOAP web service interface of the platform.

The attached .zip file contains the Perl API installer. Refer to the [Perl API product documentation](https://docs.servicenow.com/ "Perl API product documentation") for installation instructions.

Please note, as of New York release, these scripts are no longer supported and will not be updated
