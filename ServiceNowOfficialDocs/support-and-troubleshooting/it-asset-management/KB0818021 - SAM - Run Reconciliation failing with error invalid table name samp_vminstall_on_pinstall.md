## Issue

When we attempt to execute "Run Reconciliation" underneath Software Asset Management, the operation fails. We could use some assistance identifying why this is occurring, as we are hoping to use the tool to rationalize discovery data against entitlements.

## Resolution

Place an change request from HI service catalog to get the Microsoft publisher pack for software asset management activated on the instance.
