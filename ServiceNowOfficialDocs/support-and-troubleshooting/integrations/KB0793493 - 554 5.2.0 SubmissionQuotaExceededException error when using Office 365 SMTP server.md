## 554 5.2.0 SubmissionQuotaExceededException error when using Office 365 SMTP server

  

### Issue

When using a Microsoft Office 365 SMTP server to send emails from the instance, some emails may not be delivered to recipients. When you check the logs, the following message appears:

Warning 554 5.2.0 STOREDRV.Submission.Exception:SubmissionQuotaExceededException; Failed to process message due to a permanent exception with message The message can't be submitted because the sender's submission quota was exceeded. SubmissionQuotaExceededException: The message can't be submitted because the sender's submission quota was exceeded.

This issue resides on the Microsoft side and is caused by exceeding the throttling limit for the SMTP Authentication protocol, though other causes are possible.

### Release

All

### Cause

The issue could be caused by exceeding throttling limit for the SMTP Authentication protocol but other causes are possible as well.

### Resolution

This issue resides on Microsoft side. 

1\. Check the instance email logs to confirm the error message appears as shown above. 

2\. Contact your mail admin, providing the collected details.

3\. If the issue is not resolved by your mail admin, escalate to Microsoft Support with the same information.

See [https://learn.microsoft.com/en-us/troubleshoot/exchange/email-delivery/ndr/mapiexceptionnotfound-ndr](https://learn.microsoft.com/en-us/troubleshoot/exchange/email-delivery/ndr/mapiexceptionnotfound-ndr) for details.
