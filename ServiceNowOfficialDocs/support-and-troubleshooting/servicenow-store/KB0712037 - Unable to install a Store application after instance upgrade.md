## Unable to install a Store application after instance upgrade

  

### Issue

After upgrading an instance, the latest version of a ServiceNow Store application that is compatible with the upgraded version of the instance does not show up in the Store Applications -> Downloads tab in the ServiceNow Store.

### Release

N/A

### Resolution

After the upgrade, it takes some time for the [ServiceNow Store](https://store.servicenow.com/) to sync with the new version of the instance. Please allow one business day for the application(s) to be available for install.

If the application(s) are not available after some time, contact Now Support.
