## Validate Application button is missing or does not appear to function correctly

  

### Issue

After installing the Certification Self Test Tool application from the ServiceNow Store, customers may run into an issue where the Validate Application UI action does not function correctly (i.e., clicking on it does not do anything), or it simply does not appear on the form when it should.

### Release

All releases

### Cause

The application installation may be corrupted and requires removal and reinstallation.

### Resolution

Uninstalling and then reinstalling the Certification Self Test Tool application should resolve the issue.
