## Microsoft 365 Software Entitlement not being updated

  

### Issue

The Microsoft 365 integration is currently active, properly configured, and executing data collection jobs successfully. However, license entitlements are not being updated in ServiceNow, even though the integration is fully operational.  
  

### Release

N/A

### Resolution

Please note that entitlements are not updated automatically; they need to be updated manually.
