## 'Service Interruption - Instance is unavailable' During Upgrade or Scheduled Software Update on Server

  

### Issue

An instance upgrade or scheduled software update on server change (whether a patch or family release or regular scheduled maintenance) can result in an instance outage or a node being unavailable or restarted. You might receive the below message when trying to access the instance:

'Service Interruption - This instance is unavailable. If service does not restore promptly, please file an incident in the ServiceNow online Support Portal or contact Customer Support via phone.'

![Service Interruption screenshot](sys_attachment.do?sys_id=540f6dac9335fa58c2513f986cba1045 "Service Interruption screenshot")

### Release

### Cause

Check [Now Support](https://support.servicenow.com/now "Now Support") for any changes for the respective instance that is in progress that may be causing this outage.

### Resolution

If still within the maintenance window, it may help to wait for the maintenance window to complete, as this is an expected or planned outage.

If the maintenance window has passed and the instance is still not reachable, contact Now Support.
