## Reference lists in the mobile UI display last update time

  

### Issue

On mobile reference lists, the time of the record's last update is displayed in blue on the right edge of the screen.

The issue can be seen by navigating to a record in the mobile UI that contains a reference field, and tapping the **\>** icon on the right edge to populate the field. In the resulting reference list, the updated dates of the selectable items are displayed on the right edge of the screen.

![Mobile view of the search to pick a group](https://support.servicenow.com/sys_attachment.do?sys_id=0c0dc1f9477522d0d1a5ab29736d43a6 "Mobile view of the search to pick a group")

### Cause

This is expected behavior for a reference field selection in the Mobile UI.

### Resolution

 Currently, there are no options to change or remove this information from the list. Although this is working as designed, an Enhancement Request has been created to request the ability to change this configuration. New information will be provided as it becomes available.
