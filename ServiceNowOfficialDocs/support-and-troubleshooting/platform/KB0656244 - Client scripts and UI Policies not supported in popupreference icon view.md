## Client scripts and UI Policies not supported in popup/reference icon view

  

### Issue

Client scripts and UI Policies not supported in popup/reference icon view

  
  

# Description

* * *

Client scripts and UI Policies are not supported in popup/reference icon view.

This behavior is by design. 

An option is to remove the field/fields or variables from the Sys\_popup view, in case the scripts are trying to hide it.

# Applicable Versions

* * *

all versions
