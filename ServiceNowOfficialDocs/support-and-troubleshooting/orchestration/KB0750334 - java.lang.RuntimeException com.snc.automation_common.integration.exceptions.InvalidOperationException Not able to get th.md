## java.lang.RuntimeException: com.snc.automation\_common.integration.exceptions.InvalidOperationException: Not able to get the credential with the sysId:

  

### Issue

 

When performing test connection on a JDBC orchestration activity, the below error is seen:

Connection Failed: java.lang.RuntimeException: com.snc.automation\_common.integration.exceptions.InvalidOperationException: Not able to get the credential with the sysId:<credential\_sys\_id>. If the credential is an external credential, please verify your external credential setup/configuration. Otherwise, please check if the credential is active.

### Release

Any

### Cause

1) The most unlikely cause is that the credential is inactive

2) The most common cause is that if there are invalid/orphaned credentials in the instance.

3) If there are invalid/orphaned credentials in the instance, the credential sync does not happen with the MID Server and therefore the InvalidOperationException occurs.

### Resolution

1) Make the credential active.

2) Remove invalid/orphaned credentials and run test connection on the JDBC activity again

3) Check to see if it has any issue on the MID server issue table (Invalidate/Validate). Verify that all MIDs being used have valid credentials.
