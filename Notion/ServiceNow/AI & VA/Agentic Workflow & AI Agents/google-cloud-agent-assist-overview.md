# Google Cloud Agent Assist (product overview)

Part of [Gemini Enterprise for Customer Experience](https://cloud.google.com/products/gemini-enterprise-for-customer-experience). Provides in-the-moment coaching and next-best action guidance to customer care representatives, helping them resolve customer issues faster and with greater accuracy.

- Provide answers to customer questions from a centralized knowledge base
- Transcribe calls in real-time and automate post-interaction summaries

## Benefits (as marketed)

- **Reduce costs** — help service reps handle 28% more conversations, reduce operational costs, decrease average customer hold time, handle peak traffic efficiently
- **Improve CSAT** — consistent, high-quality responses, quicker training by learning from high-performing agents
- **Respond quicker** — 15% quicker response time using Smart Reply, faster answers drawn from a central knowledge base

## Key features

- **AI Coach** — in-the-moment contextual assistance, step-by-step guidance, coaching that improves response quality and time to resolution
- **AI Trainer** — interactive simulations and personalized training for new hires / less experienced staff, in a safe controlled environment
- **Knowledge base answers** — AI-generated suggested content from business/customer data sources (website, knowledge base, documentation, CRM, others)
- **Live transcription + post-interaction summaries** — transcribes calls in real time; after the interaction, automatically summarizes the interaction, key takeaways, and next steps using Google Gemini models — reduces after-call work time and average handle time
