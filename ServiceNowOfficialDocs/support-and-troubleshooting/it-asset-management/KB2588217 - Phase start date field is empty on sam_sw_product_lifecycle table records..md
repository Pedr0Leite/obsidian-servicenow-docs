## Issue

Software Product Lifecycles (sam\_sw\_product\_lifecycle) table has records having empty Phase start date (start\_date) field like below screenshot.  
![](/sys_attachment.do?sys_id=cb4cb4629330f6d4d9743f986cba10f8)

## Resolution

Please check Lifecycle code (lifecycle\_code) field of the record. It might have code written on KB1642485.
