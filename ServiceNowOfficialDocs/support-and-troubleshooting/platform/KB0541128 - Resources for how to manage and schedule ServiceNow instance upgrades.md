## Resources for how to manage and schedule ServiceNow instance upgrades

  

### Issue

Upgrading your ServiceNow instance gives you access to the latest features, patches, and security updates. Manage upgrades through Now Support using the **Instances Dashboard** and **Upgrade Wizard**. This article provides a high-level overview and links to detailed guides for each upgrade task.

If you cannot schedule an upgrade or patch, check for an existing change request (CHG) in **Instances** \> **Instances Dashboard**. Only one upgrade CHG is allowed per instance at a time. 

**Note:**  ServiceNow security policy prevents internal employees, including Support and SAM teams, from scheduling or managing upgrades for customer instances. Customers must perform these actions using their own credentials.
