## Issue

# Description

* * *

Where is password reset enrollment data stored?

# Procedure

* * *

All the enrollment data is available in 'pwd\_enrollment' table.

If the enrollment record is deleted for a user, the user will be prompted to re-enroll for the verification.

# Applicable Versions

* * *

All
