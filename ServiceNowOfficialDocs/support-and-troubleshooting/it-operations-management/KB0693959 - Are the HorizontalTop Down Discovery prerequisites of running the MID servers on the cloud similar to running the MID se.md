## Are the Horizontal/Top Down Discovery prerequisites of running the MID servers on the cloud similar to running the MID servers on-premise?

  

### Issue

The prerequisites of MID servers hosted on cloud providers which are used for Horizontal and Top-down discovery operations. 

The same requirements for on-premise Horizontal and Top-down discovery apply on Cloud-Hosted MID servers in terms of internal and external network requirements and credentials.

Please check the following list of documents about Discovery, MID server setup requirements, Discovery credentials, Discovery Classification & Identification:

-   [Discovery basics](https://docs.servicenow.com/csh?topicname=c_GetStartedWithDiscovery.html&version=latest "Discovery basics")
-   [MID Server Connection Prerequisites](<https://docs.servicenow.com/ .html> "MID Server Connection Prerequisites")
-   [Discovery classifiers](https://docs.servicenow.com/csh?topicname=discovery-classifiers.html&version=latest)
-   [Discovery identifiers](https://docs.servicenow.com/csh?topicname=c_DiscoveryIdentifiers.html&version=latest)
