## Integration Hub REST step fails - No implementation for com.snc.core\_automation\_common.connections.IRetryInfoProvider was bound

  

### Issue

Integration Hub REST step fails - No implementation for com.snc.core\_automation\_common.connections.IRetryInfoProvider was bound

### Cause

REST step has 'Enable Retry Policy' check marked but no policy is selected

### Resolution

REST step has 'Enable Retry Policy' check marked but no policy is selected

Either select a Retry Policy or disable this option
