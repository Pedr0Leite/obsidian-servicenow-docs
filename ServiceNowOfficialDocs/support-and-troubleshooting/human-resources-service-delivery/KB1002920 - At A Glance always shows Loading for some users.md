## At A Glance always shows "Loading" for some users

  

### Issue

At A Glance side panel on the HR Agent workspace, it always shows Loading instead of HR Profile Details.

### Cause

The issue occurs because the user profile has the First Name blank.

The issue is observed only while the First name is blank, for Last name the issue is not observed.

### Resolution

If we update the First Name field then the issue is not observed.
