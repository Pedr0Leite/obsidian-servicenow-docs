## How to disable messages "No mid found to trigger credential-less discovery for <\>" in discovery logs

  

### Issue

# Description

* * *

How to disable messages "No mid found to trigger credential-less discovery for <<IP Address>>" in discovery logs

# Procedure

* * *

System Property 'mid.discovery.credentialless.enable' is enabled by default with discovery plugin. If you disable this system property by changing the value to false these messages will not be triggered. 

# Applicable Versions

* * *

ALL

# Additional Information

* * *

Please see this documentation if you want to read more about the property: [Credential-less Discovery with Nmap](https://docs.servicenow.com/csh?topicname=nmap-credential-less-discovery.html&version=latest "Credential-less Discovery with Nmap")
