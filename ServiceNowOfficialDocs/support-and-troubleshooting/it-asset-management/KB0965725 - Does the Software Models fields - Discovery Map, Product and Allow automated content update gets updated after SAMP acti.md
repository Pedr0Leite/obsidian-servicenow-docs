## Does the Software Models fields - "Discovery Map", "Product" and "Allow automated content update" gets updated after SAMP activation?

  

### Summary

With the activation of Software Asset Management Professional:

The following fields will not be updated for the existing Software Models \[cmdb\_software\_product\_model\] records especially when the records came from the old SAM.

\- Allow automated content update

\- Product

\- Discovery Map

  

At the moment, the OOTB design does not have the feature to automatically populate these fields for existing records.

To be able to update the records, it needs to be manually updated.

  

### Release

All
