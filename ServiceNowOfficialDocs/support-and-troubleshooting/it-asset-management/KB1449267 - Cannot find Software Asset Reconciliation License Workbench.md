## Issue

Users who try to navigate to Software Asset > Reconciliation > License Workbench will find that License Workbench is not where to be found after installing the latest Software Asset Management plugin package.

Users have also reported that column data are not aligned with headers in tables within License Workbench.

## Resolution

Installing the latest Software Asset Management will replace License Workbench with Software Asset Workspace.

Navigate by Software Asset > Software Asset Workspace
