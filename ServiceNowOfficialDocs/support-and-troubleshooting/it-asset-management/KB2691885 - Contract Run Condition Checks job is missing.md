## Contract: Run Condition Checks job is missing

  

### Issue

"Contract: Run Condition Checks" job is missing on the instance.

### Release

Yokohama

### Resolution

The scheduled job “Contract: Run Condition Checks” has been updated and is now available under the name “Contract Compliance Checks.”  
This change is a naming update only and does not affect existing functionality.
