## The service did not start due to a logon failure - MID Server Service

  

### Issue

MID server is DOWN when trying to upgrade and gives the below error when trying to start the MID server service.

"The service did not start due to a logon failure"

### Release

All

### Resolution

The Windows/Infrastructure team needs to fix the below error. This is probably due to incorrect password or sync issues for the user used to run the MID server service.

"The service did not start due to a logon failure"
