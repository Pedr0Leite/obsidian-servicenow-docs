## Missing 'New' Button in Consumable Related List on Hardware Asset Workspace

  

### Issue

The 'New' button is not visible in the Consumables related list when accessing a consumable model in the Hardware Asset Workspace.

### Release

This is not release specific.

### Resolution

Install Enterprise Asset Management, which includes a Declarative Action Assignment record for this purpose.
