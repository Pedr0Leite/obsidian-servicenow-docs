## Journey Task Descriptions Not Visible in Now Mobile App

  

### Issue

Journey task descriptions are not visible in the Now Mobile app during employee onboarding, though they appear in the desktop portal.

### Release

Any

### Cause

The Now Mobile app does not support displaying values from global description or global short description fields.

### Resolution

-   Use the standard task description fields instead of global description fields for journey tasks.
-   Validate that descriptions appear correctly in the Now Mobile app after updating the fields.
