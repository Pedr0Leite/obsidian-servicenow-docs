## Issue

Starting in Istanbul, the classic Reports list **Reports > View / Run** layout is no longer available.

Previously, it was possible to enable the older version of the Reports list layout by setting the system property glide.ui.report.new\_home to **false**. This property setting no longer has an effect and only the redesigned Reports list layout is available. 

Until the Helsinki release, domain separation was not supported for the new Reports list layout. From Helsinki onward, domain separation is supported.
