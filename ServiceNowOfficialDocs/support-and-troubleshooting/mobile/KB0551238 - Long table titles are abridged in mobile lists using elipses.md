## Long table titles are abridged in mobile lists using elipses

  

### Issue

# Symptoms

* * *

The description of records on Mobile UI lists are determined by [table titles](https://docs.servicenow.com/csh?topicname=t_DefiningMobileLayout.html&version=latest). When these titles are longer than the available screen space will allow, the instance displays a cut-off version of the title, using an ellipsis ( ... ) symbol at the end to indicate that there is a longer title.

Here's an example of what this will look like.  
  
![](sys_attachment.do?sys_id=5b79e022db42b450e515c22305961919)

# Release

* * *

ALL

# Cause

* * *

This is intentional behavior, done to fit the list within the screen limitations of mobile devices, while still indicating that there is a longer title.

# Resolution

* * *

Clicking into the record displays the complete short description in the form's title bar, wrapped if necessary. Switching the phone to the landscape layout also allows you to quickly see the complete line in the list view.
