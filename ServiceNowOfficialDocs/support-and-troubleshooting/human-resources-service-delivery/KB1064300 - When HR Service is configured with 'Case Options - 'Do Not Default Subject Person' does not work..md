## Issue

When HR Service is configured with 'Case Options -> Do Not Default Subject Person' does not work.  
Open an HR Case from the advanced view or from the HR Agent Work Space, and the 'Open for' user is set as 'Subject person' by default and on HR case creation form.  
When Case created from the ESC portal, subject person is not auto populated.

## Resolution

This should be clearly documented in our current documentation.

DOC74878 was raised sometime back to address this but document is not updated yet.

A new doc enhancement request - DOC145054 is created to address this.
