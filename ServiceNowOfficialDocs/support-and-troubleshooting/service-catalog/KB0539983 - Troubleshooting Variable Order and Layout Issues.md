## Troubleshooting Variable Order and Layout Issues

  

### Issue

No variables on the form or

Variables are laid out incorrectly on the order item screen.

### Resolution

Determine whether any of the troubleshooting steps below are true for your environment. Each step links to an article that can help you eliminate possible causes and take corrective action as necessary. 

1.  Determine if the correct container variables are being used. For more information, see [KB0539982](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0539982): Determining if you are using the correct container variable.
2.  Determine if the setup for ordering on variable sets and item variables may be misconfigured or contain empty values. For more information, see [Variable set layout](https://docs.servicenow.com/csh?topicname=c_DefineVariableSetLayout.html&version=latest).
3.  Determine if permissions are impacting the layout. For more information, see [KB0539984](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB0539984): Determining if permissions are impacting the Layout.
