## Unable to get the non-english value of translated text field or translated html field when using the email template

  

### Issue

# Symptoms

* * *

Unable to get the non-english value of translated text field or translated html field when using the email template

# Release

* * *

All releases

# Cause

* * *

Out of box, the email variables will be sent using the system language which is English by default. 

# Resolution

* * *

While we do not have any officially supported methods to send emails where the email variable is translated to a language other than default system language, please refer to the following community post that provides a customization.  
  
Please note that because this is a community post and it is a customization which is outside the scope of the Customer Support team.
