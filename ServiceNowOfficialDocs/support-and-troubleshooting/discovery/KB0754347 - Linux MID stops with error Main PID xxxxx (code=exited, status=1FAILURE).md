## Linux MID stops with error "Main PID: xxxxx (code=exited, status=1/FAILURE)"

  

### Issue

Linux server stops with an error of "Main PID: xxxxx (code=exited, status=1/FAILURE)"

### Release

All

### Resolution

This is the expected results from killing the MID server process and should not be considered an issue.
